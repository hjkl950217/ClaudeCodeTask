# 经验和文档

本目录用于保存**适合长期保存的记录和文档**：排查过程、踩坑经验、方案决策、设计复盘等，供后续开发和未来会话查阅。与 `docs/`（开发过程性文档，仅本地）的区别：这里的内容定位为长期有效、可反复参考的经验沉淀。

## 目录结构

- `性能调试/` —— 性能问题排查的探针方法、实测数据、结论与最终代码。
  - `claude接管时序探针.md` —— claude 启动「接管屏幕」时序探针复盘（决策 88）：raw / 标题 / 光标三个候选信号的实测时间线，结论为光标离开行号与渲染同步，spinner 据此恰好贴住接管瞬间熄灭。
- `README.md` —— 本索引。

## 约定

- 新增长期有效的经验/文档时，先判断归属子目录，再在下方登记索引条目。
- 索引条目格式：`- 文件名 —— 一句话说明（关联决策编号）`。
