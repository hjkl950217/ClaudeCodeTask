# v0.7.0

> 这一版新增 `cct update`：查一下 PowerShell Gallery 的最新版本，有更新就直接装上，不用再记模块安装命令。

> *This release adds `cct update`: it checks the latest version on the PowerShell Gallery and installs it when there is an update, so you no longer need to remember the module install command.*

## 新功能

*New features*

- **`cct update` 直接更新自己**：运行后先显示当前版本和 Gallery 最新版本。已经是最新版就直接告诉你；有新版本就自动安装，装完提示重开终端生效。

  *`cct update` updates cct itself: it prints your current version and the latest version on the Gallery. If you are already up to date, it says so and stops. If there is a newer version, it installs it and tells you to reopen the terminal.*

- **不用记 `Install-Module` 参数**：无论模块当初是 `Install-Module` 装的，还是手动拷贝到模块目录的，命令都会选对更新方式。

  *No need to remember `Install-Module` parameters: the command picks the right update path whether the module was installed with `Install-Module` or copied into the module directory by hand.*

## 使用

*Usage*

```powershell
cct update
```

> 更新会装到新的版本目录，不影响当前已打开的会话；重开终端（或先 `Remove-Module ClaudeCodeTask`）后生效。

> *The update installs into a new version directory and does not affect the session you already have open. Reopen the terminal (or run `Remove-Module ClaudeCodeTask` first) in order for it to take effect.*

## 安装与更新

*Installation and update*

从 PowerShell Gallery 安装或更新到最新版：

*Install or update to the latest version from the PowerShell Gallery:*

```powershell
# 全新安装
# Fresh install
Install-Module -Name ClaudeCodeTask -Scope CurrentUser

# 更新到 0.7.0
# Update to 0.7.0
Update-Module -Name ClaudeCodeTask -Scope CurrentUser -Force
```

更多用法见 README 或 `cct -h`。

*More usage details in the README or `cct -h`.*
