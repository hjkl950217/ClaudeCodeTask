# v0.2.0

> v0.2.0 让你像用普通命令行工具一样用 cct——不用进全屏界面，也能在熟悉的终端里把会话列出来、查出来、直接跑起来。

## 新功能

- **指令式用法**：`cct list` 列出会话、`cct find <词>` 查找、`cct run <词>` 直接启动；想「把上次那个调优的会话跑起来」，一条命令就够。
- **按会话 ID 精准进入**：`cct run -i <会话ID>` 直达指定会话，关键词撞车也不怕；配 `--dry-run` 可先演练看要执行的命令。
- **列表更聚焦**：默认只列真实会话，文件夹不再单独占一行（需要时可用配置文件恢复）。
- **标题来源可辨**：输出能看出会话名是你手动命名的，还是 AI 自动生成的。
- **版本信息更全**：`cct -v` 显示版本号 + 项目地址。

## 修复与优化

- 进入会话时转圈动画在 claude 真正接管后立即停止，不再空转。
- 内核（C#）+ 外壳（PowerShell）分层重构，配 Pester 单测，整体更稳。

## 安装与使用

> 从 0.2.0 起模块名统一为 **ClaudeCodeTask**（此前为 `ClaudeCodeTask.UI`），Gallery 包名与源码文件名均以此为准。

推荐从 PowerShell Gallery 安装：

```powershell
Install-Module -Name ClaudeCodeTask -Scope CurrentUser
```

或下载本页 Assets 里的 **Source code** 解压，手动导入：

```powershell
Import-Module "<解压路径>\ClaudeCodeTask.UI\ClaudeCodeTask.psm1" -Force
cct
```

更多用法见 `cct -h`。
