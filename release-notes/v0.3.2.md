# v0.3.2

> 这一版把模块的对外介绍全面改为中英双语，方便不同语言的读者。PowerShell Gallery 的模块简介扩充为完整的功能概述（中文、英文各成段），README 每一段中文下都附英文说明，GitHub 仓库简介也改为双语。阅读时不再有中文夹英文的别扭感——中文一整句、英文一整句，各自独立成行。

> *This release makes all external documentation fully bilingual so readers in either language get the same comfortable experience. The PowerShell Gallery module description is expanded into a full feature overview with separate Chinese and English paragraphs; every README paragraph carries an English explanation below it; and the GitHub repo description is bilingual too. No more mixing languages inside one sentence — a whole Chinese sentence, then a whole English sentence, each on its own line.*

## 修复与优化

*Fixes and improvements*

  *The module description is expanded and bilingual: the PSGallery description grows from one line into a full feature overview with separate Chinese and English paragraphs; tags now include `claude-code`, `selector`, `sessions`, `launcher`, `productivity` and more for easier discovery.*

- **GitHub 仓库简介改为双语**：仓库首页的简介现在同时展示中文和英文。

  *The GitHub repository description is now bilingual, shown in both Chinese and English on the repo homepage.*

## 安装与使用

*Installation and usage*

推荐从 PowerShell Gallery 安装：

*Recommended: install from the PowerShell Gallery.*

```powershell
Install-Module -Name ClaudeCodeTask -Scope CurrentUser
```

**已有旧版本？更新到最新版：**

***Already on an older version? Update to the latest:***

```powershell
# 更新到最新版（含 0.3.2）
# Update to the latest version (includes 0.3.2)
Update-Module -Name ClaudeCodeTask

# 若上一命令因权限报错，显式指定用户级作用域重试
# If the command above fails on permissions, retry with an explicit user scope
Update-Module -Name ClaudeCodeTask -Scope CurrentUser -Force
```

> 更新前先确认当前版本：`Get-Module -Name ClaudeCodeTask -ListAvailable`；若模块已在本会话加载，更新后需**重开终端**（或先 `Remove-Module ClaudeCodeTask` 再输入 `cct`）才会生效。

> *Check the current version first: `Get-Module -Name ClaudeCodeTask -ListAvailable`; if the module is already loaded in the session, **reopen the terminal** after updating (or `Remove-Module ClaudeCodeTask` and type `cct` again).*

或下载本页 Assets 里的 **ClaudeCodeTask.zip** 手动安装：解压后把 `ClaudeCodeTask` 文件夹放进 PowerShell 模块目录（Windows 为 `$HOME\Documents\PowerShell\Modules`），然后：

*Or download the **ClaudeCodeTask.zip** asset on this page and install manually: extract it and put the `ClaudeCodeTask` folder into your PowerShell module directory (Windows: `$HOME\Documents\PowerShell\Modules`), then:*

```powershell
Import-Module ClaudeCodeTask -Force
cct -h
```

更多用法见 README 或 `cct -h`。
