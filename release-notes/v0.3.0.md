# v0.3.0

> v0.3.0 新增 `cct clear` 清理命令：默认一键清掉 cct 自己的扫描缓存，让下次重启全量重新扫描；加上 `-cc` 还能按「会话行数」判定，帮你像手动整理那样删除多余的历史会话——删之前会先打印过滤规则和待删清单，确认后才动手。

## 新功能

- **`cct clear`——清扫描缓存**：删除 `~/.cct/cache.json`，下次启动 cct 时全量重建扫描结果。适合觉得列表「卡在旧数据」时用。只动缓存文件，`config.json` 配置不受影响。
- **`cct clear -cc`——清理多余会话**：把「整理历史会话」的手工操作变成一条命令。按每个目录里的会话 `.jsonl` 行数近似判断对话次数，每目录保留「行数 ≥ 阈值」里最新的一个，其余会话、被删会话的附属目录（subagents/tool-results/workflows）、孤立目录、以及整目录里会话都太少时连同 memory 一起列入删除。
  - **先预览后删除**：执行前打印三样——过滤规则、将保留的会话、待删清单（类型/路径/理由/大小），最后交互确认 `[y/N]` 才真正删除。
  - **非交互环境安全兜底**：没有终端（无 TTY）且未加 `--yes` 时，只出预览不删。
  - **`--yes`**：跳过交互确认直接删（CI / 脚本用）。
  - **`--dry-run`**：只看预览，不删。
  - **`--keep <数>`**：调整每目录保留的最新会话个数（默认 1）。
  - **`--min <行数>`**：调整会话有效行数阈值（默认 20）。
  - 排除路径沿用配置文件里的 `excludePathPatterns`（如 worktrees / Temp），这些目录不参与判定。

## 使用示例

```powershell
cct clear                 # 清 cct 扫描缓存，下次全量重建
cct clear -cc --dry-run   # 预览会删哪些多余会话（不删）
cct clear -cc             # 预览 + 确认后删除
cct clear -cc --yes       # 跳过确认直接删（脚本用）
cct clear -cc --keep 3    # 每目录多留几个最新会话
```

## 安装与使用

推荐从 PowerShell Gallery 安装：

```powershell
Install-Module -Name ClaudeCodeTask -Scope CurrentUser
```

**已有旧版本？更新到最新版：**

```powershell
# 更新到最新版（含 0.3.0）
Update-Module -Name ClaudeCodeTask

# 若上一命令因权限报错，显式指定用户级作用域重试
Update-Module -Name ClaudeCodeTask -Scope CurrentUser -Force
```

> 更新前先确认当前版本：`Get-Module -Name ClaudeCodeTask -ListAvailable`；若模块已在本会话加载，更新后需**重开终端**（或先 `Remove-Module ClaudeCodeTask` 再输入 `cct`）才会生效。

或下载本页 Assets 里的 **ClaudeCodeTask.zip** 手动安装：解压后把 `ClaudeCodeTask` 文件夹放进 PowerShell 模块目录（Windows 为 `$HOME\Documents\PowerShell\Modules`），然后：

```powershell
Import-Module ClaudeCodeTask -Force
cct -h
```

更多用法见 `cct clear -h`。
