# v0.3.1

> v0.3.1 修复两类「列表不对劲」：`claude -c`/`--resume` 续接会话产生的重复卡片不再出现（同一对话链只留最新一张）；只剩零碎会话的目录现在直接显示为可进入的会话卡，卡片标题和进入后的会话标题完全一致。另外同步脚本经过一轮加固，各种异常情况都有明确提示。

## 修复与优化

- **续接分叉不再重复出卡**：用 `claude -c` 或 `--resume` 继续会话时，Claude Code 会在同一目录生成携带历史的新会话文件。此前祖先会话和续接会话会各自出一张卡（标题、路径都一样）；现在同一对话链只显示最新的一个入口，旧卡自动折叠。
- **碎片目录直接可进**：目录里只剩多次续接产生的零碎会话（此前因消息数不足而被过滤，只能看到文件夹卡片）时，现在自动把最新的有标题会话升格为会话卡。卡片标题 = 进入后的会话标题，且用精确恢复（`--resume`）代替「接续最近」，进入的就是卡片上这个会话。
- **无标题的目录保持原样**：没有标题的目录仍按文件夹卡片显示，不受本次调整影响。
- **扫描内核升级**（CctScannerV5）：为支持上面两项，扫描时额外识别会话之间的续接血缘；扫描缓存格式升级，旧缓存会在下次启动时自动重建，无需手动清理。
- **同步脚本加固**（`sync-to-installed.ps1`，自装用户）：备份先行（备份失败不覆盖任何文件）、单文件被占用不中断整体并在最后汇总提示、覆盖后新开子进程烟测验证「装上即可用」、旧内核驻留的终端自动跳过热切换并说明原因（.NET 程序集无法在进程内替换，新开终端即可）、PowerShell 5.1 下给出明确提示。
- **集中元数据**：版本号、仓库地址、发版说明、构建代理收敛到仓库根 `build-metadata.json` 单一文件维护，发版不再多处手改。

## 安装与使用

推荐从 PowerShell Gallery 安装：

```powershell
Install-Module -Name ClaudeCodeTask -Scope CurrentUser
```

**已有旧版本？更新到最新版：**

```powershell
# 更新到最新版（含 0.3.1）
Update-Module -Name ClaudeCodeTask

# 若上一命令因权限报错，显式指定用户级作用域重试
Update-Module -Name ClaudeCodeTask -Scope CurrentUser -Force
```

> 更新前先确认当前版本：`Get-Module -Name ClaudeCodeTask -ListAvailable`；若模块已在本会话加载，更新后需**重开终端**（或先 `Remove-Module ClaudeCodeTask` 再输入 `cct`）才会生效。

或下载本页 Assets 里的 **ClaudeCodeTask.zip** 手动安装：解压后把 `ClaudeCodeTask` 文件夹放进 PowerShell 模块目录（Windows 为 `$HOME\Documents\PowerShell\Modules`），然后：

```powershell
Import-Module ClaudeCodeTask -Force
cct -h
```

更多用法见 `cct -h`。
