# v0.6.0

> 这一版把「命名会话」变成目录入口：命名过就保留，同名多段合并成一张卡；选中卡片后按配置的启动命令进入，和直接在该目录运行 claude-dc 一致。缓存结构不变，无需清理。

> *This release makes a named session the entry point for its directory: a named session is kept even if it is short, and segments sharing the same name are merged into one card. Selecting a card runs your configured launch command in the session's start directory, matching how claude-dc behaves in that directory. The cache format is unchanged.*

## 新功能

*New features*

- **命名会话不再受消息条数限制**：只要给会话起过名字，哪怕只有一条消息，它也会作为该目录的入口出现在列表里。命名后立即退出，下次仍能从 cct 看到它。

  *Named sessions are no longer limited by message count: once a session has a name, it appears as the entry point for its directory even if it has only one message. Name it and exit right away — it is still there next time.*

- **同名多段合并成一张卡**：`/clear` 之后继续聊会产生新的会话文件，旧版把它们当成互不相干的多条记录。现在同名会话只出一张卡，卡片指向文件时间最新的那段，与 `claude -c` 的选择口径一致。

  *Segments sharing the same name are merged into one card: after `/clear`, continuing the conversation creates a new session file. The previous version treated the segments as unrelated records. Now a single card is shown for sessions with the same name and points to the most recently written file, matching how `claude -c` picks a session.*

- **卡片启动方式与直接运行 claude-dc 一致**：选中卡片后，cct 先切到该会话的启动目录，再执行你在配置文件里写的启动命令。你在目录下直接运行 `claude-dc`，和从 cct 进入这张卡，效果相同。

  *Cards launch the same way as running claude-dc directly: after you pick a card, cct changes to the session start directory and runs the launch command from your config. Running `claude-dc` in that directory has the same effect as entering the card from cct.*

## 修复与优化

*Fixes and improvements*

- **`/clear` 后只说一句话的新会话也能进列表**：新会话会继承原来的名字，旧版因消息数不够把它过滤掉，卡片一直指向旧会话。现在它会正常出现。

  *A new session with a single message after `/clear` is now listed: the new session inherits the original name. The previous version filtered it out for having too few messages, so the card kept pointing at the old session. It now appears normally.*

- **`cct run -i` 仍可直达被合并的旧会话**：按会话 ID 查找不再依赖列表里的卡片，被合并掉的历史会话也能精确恢复。

  *`cct run -i` can still reach a merged-away session: lookup by session ID no longer depends on the card list, so older sessions that were merged into one card can still be resumed precisely.*

- **未命名的目录保持原逻辑**：没有任何命名会话的目录，仍然要聊到阈值以上才自动出卡。

  *Directories without a named session keep the previous behavior: they still need to reach the message threshold before a card is created automatically.*

## 安装与更新

*Installation and update*

从 PowerShell Gallery 安装或更新到最新版：

*Install or update to the latest version from the PowerShell Gallery:*

```powershell
# 全新安装
# Fresh install
Install-Module -Name ClaudeCodeTask -Scope CurrentUser

# 更新到 0.6.0
# Update to 0.6.0
Update-Module -Name ClaudeCodeTask -Scope CurrentUser -Force
```

> 更新后若 cct 已在本会话加载，需**重开终端**（或先 `Remove-Module ClaudeCodeTask`）再输入 `cct` 才会生效。

> *If cct is already loaded in the session, **reopen the terminal** (or `Remove-Module ClaudeCodeTask`) before typing `cct` for the update to take effect.*

更多用法见 README 或 `cct -h`。

*More usage details in the README or `cct -h`.*
