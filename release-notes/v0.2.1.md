# v0.2.1

> v0.2.1 修好了「装完跑不起来」的问题——从 PowerShell Gallery 或本页 zip 安装后，现在直接能 `cct` 启动；同时列表不再把同名历史会话藏起来，你保存过的每个真实会话都能找到、都能进。

## 修复与优化

- **安装即用**：上一版从 Gallery 安装后启动报错、zip 解压也不能用，根因是内核动态库没有随模块一起打包。本版把内核打进模块包，安装后直接可用，不再需要额外拷贝或手工放置文件。
- **同名会话不再被隐藏**：多个同名（同标题）的历史会话此前只留最新一条，旧的同名会话在列表里看不到、也进不去；现在全部各自列出，靠最近活动时间区分，逐个可进。
- **列表更干净**：某个文件夹里已有可恢复的会话时，该文件夹不再单独占一行（由会话条目直接代表），文件夹只出现在没有可恢复会话的纯目录下。

## 安装与使用

从 0.2.0 起模块名统一为 **ClaudeCodeTask**（此前为 `ClaudeCodeTask.UI`），Gallery 包名与源码文件名均以此为准。

推荐从 PowerShell Gallery 安装：

```powershell
Install-Module -Name ClaudeCodeTask -Scope CurrentUser
```

或下载本页 Assets 里的 **ClaudeCodeTask.zip** 手动安装：解压后把 `ClaudeCodeTask` 文件夹放进 PowerShell 模块目录（Windows 为 `$HOME\Documents\PowerShell\Modules`），然后：

```powershell
Import-Module ClaudeCodeTask -Force
cct
```

更多用法见 `cct -h`。
